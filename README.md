# ZerrissenenReiche
StrongholdCrusader Winterwolf-Pack
⚔️ Die Zerrissenen Reiche

Willkommen bei „Die Zerrissenen Reiche“, einem Paket für Stronghold Crusader, in dem ich meine selbst erstellten und angepassten KIs vorstelle.

Das Paket erweitert das Spiel um eine Reihe unterschiedlicher Gegner und Charaktere, die sich in Spielweise, Persönlichkeit und Stärke voneinander unterscheiden. Einige KIs befinden sich noch in Entwicklung und werden im Laufe der Zeit verbessert oder ergänzt.

Hinweis: Das Paket befindet sich weiterhin in Entwicklung. Einige KIs können sich daher noch verändern oder später überarbeitet werden.

🏰 Enthaltene KIs

Aktuell sind folgende KIs im Paket enthalten:

Anjun
Armand
Theo
Der Bulle
Bey Baran Kurtoglu
Georgier
Ghabi
Halid al-Nur
Die Maetresse
Roderic
Roi
Sultan Mehmet I
Winterwolf

Jede KI verfolgt dabei ihren eigenen Spielstil und soll für abwechslungsreiche Gefechte sorgen.

🔨 Entwicklung

Das Paket ist noch nicht vollständig abgeschlossen.

Einige KIs werden in Zukunft überarbeitet, verbessert oder angepasst. Dazu gehört beispielsweise der Winterwolf, der zu einem späteren Zeitpunkt noch verbessert werden soll.

Außerdem sind weitere KIs geplant und werden nachgereicht:

Niccolò
Nadia
Mahd

Weitere Charaktere können im Laufe der Entwicklung hinzukommen.

📦 Installation

Die enthaltenen KI-Dateien können in eurem Stronghold-Crusader-Verzeichnis installiert werden.

Je nach verwendeter Version des Spiels kann sich der entsprechende Ordner unterscheiden. Bitte achtet darauf, vor der Installation ein Backup eurer vorhandenen Dateien anzulegen.

🎮 Über das Projekt

Die Zerrissenen Reiche soll eine Sammlung verschiedener KIs für Stronghold Crusader werden, die neue Herausforderungen und abwechslungsreiche Schlachten ermöglichen.

Das Projekt befindet sich laufend in Entwicklung. Daher können sich Werte, Burgen, Strategien und das Verhalten einzelner KIs mit zukünftigen Updates verändern.
